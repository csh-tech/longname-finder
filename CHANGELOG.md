# Changelog

## [1.0.0]
- First release.
- Scans a folder recursively and lists files whose **name** (incl. extension) is 240+ characters.
- Excel report with clickable links to each file and its folder.
- Handles paths longer than 260 characters.
- English and Hebrew interface (chosen automatically from the system language).
- Translations in separate `locales/*.json` files.
- Asks where to save the report.
