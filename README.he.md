## למה זה נחוץ?

קבצים שנשמרים מוואטסאפ, מטלגרם, מרשתות חברתיות או מאתרים מקבלים לפעמים את כל טקסט
הפוסט כשם הקובץ. ב-Windows שם קובץ יכול להגיע עד **255 תווים**, ושמות שמתקרבים למגבלה
הם סיבה נפוצה לכך ש:

- סייר הקבצים נתקע או מופעל מחדש כשפותחים תיקייה או מחפשים
- אי אפשר להעתיק, להעביר, לשנות שם או למחוק קבצים
- תוכנות גיבוי וסנכרון מדלגות על קבצים

למצוא אותם ידנית זה כמעט בלתי אפשרי. LongName Finder סורק תיקייה, או כונן שלם,
ומציג לכם רשימה.

## יכולות

- סורק תיקייה וכל תתי-התיקיות שלה, כולל נתיבים ארוכים מ-260 תווים
- בודק **רק את שם הקובץ** (כולל הסיומת), בדיוק כמו ש-Windows סופר אותו
- דוח אקסל שבו השמות הארוכים ביותר מופיעים ראשונים, עם:
  - שם הקובץ והמיקום שלו
  - קישור לפתיחת הקובץ וקישור לפתיחת התיקייה
  - אורך השם ואורך הנתיב המלא
  - סימון של קבצים שנמצאים בדיוק במגבלה של 255 תווים
- תיקיות שלא היה אפשר לקרוא נרשמות בגיליון נפרד, והסריקה ממשיכה
- ממשק בעברית ובאנגלית, לפי שפת Windows שלכם
- התוכנה רק קוראת: היא **אף פעם** לא משנה שם, מעבירה או מוחקת קבצים
- קובץ `exe` אחד: לא צריך להתקין אותו, לא צריך Python ולא צריך להוריד שום דבר נוסף

## הורדה

מורידים את **`LongNameFinder.exe`** מ[הגרסה האחרונה](https://github.com/csh-tech/longname-finder/releases/latest).

> **Windows SmartScreen** עלול להציג אזהרה, כי התוכנה לא חתומה דיגיטלית.
> לוחצים **מידע נוסף**, ואז **הפעל בכל זאת**. כל קוד המקור נמצא כאן,
> ואפשר לבנות את קובץ ה-exe בעצמכם (ההסבר בהמשך).

## שימוש

1. לוחצים פעמיים על `LongNameFinder.exe`.
2. בוחרים תיקייה או כונן לסריקה.
3. בסוף הסריקה בוחרים איפה לשמור את הדוח
   (שם ברירת המחדל: `long_names_YYYYMMDD_HHMM.xlsx`), והוא נפתח באקסל.

הממשק והדוח מוצגים בשפת התצוגה של Windows (עברית או אנגלית; בכל שפה אחרת הם יוצגו באנגלית).
אפשר לבחור שפה אחרת עם `--lang`.

### שורת פקודה

<div dir="ltr">

```
LongNameFinder.exe [folder] [--min N] [-o report.xlsx] [--lang en|he]
```

</div>

| אפשרות | הסבר |
|---|---|
| `folder` | תיקייה לסריקה. בלי אפשרות זו נפתח חלון לבחירת תיקייה. |
| `--min N` | אורך שם מינימלי, כולל סיומת. ברירת מחדל: `240`. |
| `-o FILE` | שם קובץ האקסל. |
| `--lang` | בחירת שפת הממשק והדוח (`he` או `en`). |
| `--version` | הצגת מספר הגרסה. |

דוגמאות:

<div dir="ltr">

```
LongNameFinder.exe "D:\Downloads"
LongNameFinder.exe "D:\" --min 200 -o report.xlsx
```

</div>

## מה עושים עם הקבצים שנמצאו

מקצרים את השם, ושומרים את הטקסט המקורי אם הוא חשוב:

1. מסמנים את הקובץ ולוחצים **F2**, ואז **Ctrl+A** ו-**Ctrl+C** כדי להעתיק את השם הארוך.
2. קליק ימני, **מאפיינים**, הלשונית **פרטים**, ומדביקים בשדה **הערות**
   (עובד בתמונות ובקבצי Office). אפשרות אחרת היא להדביק לקובץ טקסט שנמצא לידו.
3. משנים לשם קצר.

אם גם סייר הקבצים לא מצליח לטפל בקובץ, בדרך כלל עובד
[7-Zip File Manager](https://www.7-zip.org/), או הפקודות `rename` ו-`move` ב-cmd עם הקידומת `\\?\`. לדוגמה:

<div dir="ltr">

```
move "\\?\D:\folder\long name.jpg" "D:\folder\short.jpg"
```

</div>

## שמות קבצים לעומת נתיבים ארוכים

LongName Finder בודק **רק את שמות הקבצים** (השם והסיומת), ולא את הנתיב המלא של התיקיות.

ל-Windows יש מגבלה נפרדת של **260 תווים לנתיב המלא** (כונן, תיקיות ושם הקובץ).
בגרסאות חדשות של Windows 10 ו-11 אפשר לבטל את המגבלה הזו עבור תוכנות שתומכות בכך,
על ידי הפעלת נתיבים ארוכים ברישום (Registry). מריצים את הפקודה הבאה ב-PowerShell
**כמנהל**, ואחר כך מפעילים מחדש את המחשב:

<div dir="ltr">

```powershell
New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force
```

</div>

אפשר גם לעשות את זה ידנית בעורך הרישום:

1. לוחצים **Win+R**, מקלידים `regedit` ולוחצים Enter. מאשרים את חלון ההרשאות.
2. מנווטים לנתיב הזה. אפשר גם להדביק אותו בשורת הכתובת שבראש החלון:

<div dir="ltr">

```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem
```

</div>

3. בצד ימין מחפשים את **`LongPathsEnabled`**:
   - **אם הוא קיים:** לוחצים עליו פעמיים, משנים את הערך ל-`1` ולוחצים אישור.
   - **אם הוא לא קיים:** קליק ימני על שטח ריק, **חדש**, ואז **ערך DWORD (32 סיביות)**.
     קוראים לו `LongPathsEnabled` ונותנים לו את הערך `1`.
4. מפעילים מחדש את המחשב.

אם הערך כבר `1`, הנתיבים הארוכים כבר מופעלים ואין צורך לשנות כלום.

שימו לב שגם אחרי ההגדרה הזו, ייתכן שסייר הקבצים עצמו לא יתמוך באופן מלא בנתיבים ארוכים.

## הסרת אחריות

התוכנה וההוראות האלה ניתנות **"כמות שהן" (AS IS), ללא אחריות מכל סוג**.
השימוש בהן הוא על אחריותכם בלבד. היוצר אינו אחראי לכל נזק, אובדן מידע או בעיה אחרת
שייגרמו מהשימוש בתוכנה או מביצוע ההוראות, כולל שינויים ברישום של Windows.
מומלץ תמיד לגבות קבצים חשובים לפני שמשנים את שמם, מעבירים או מוחקים אותם.

## הוספת שפה

כל הטקסטים של הממשק נמצאים בתיקייה [`locales/`](locales), קובץ JSON אחד לכל שפה.
כדי להוסיף שפה, מעתיקים את `locales/en.json` לקובץ חדש בשם של קוד השפה בשתי אותיות
(למשל `fr.json`) ומתרגמים את הערכים. את הביטויים שבתוך `{סוגריים מסולסלים}` משאירים כמו שהם.

השפה נבחרת אוטומטית לפי שפת התצוגה של Windows. אפשר גם לשים תיקייה בשם `locales`
ליד `LongNameFinder.exe`, והתוכנה תשתמש בה בלי לבנות אותה מחדש. נשמח לקבל Pull Requests עם שפות חדשות.
